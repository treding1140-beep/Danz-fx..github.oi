## 📂 Proyek Utama

### ⚡ Sistem Arbitrase Latensi
> Mengeksploitasi selisih kecepatan data antar sumber harga

- Teknologi: MQL5, Python, WebSocket API
- Fitur inti:
  - Deteksi selisih harga secara real-time
  - Manajemen risiko & batas kerugian otomatis
  - Filter sinyal palsu & perlindungan terhadap slippage
- Status: Dalam pengembangan & pengujian

### 🤖 Bot Eksekusi Otomatis
> Menjalankan strategi tanpa campur tangan emosi

- Logika masuk/keluar pasar berdasarkan kondisi terukur
- Trailing stop & penyesuaian posisi dinamis
- Pencatatan kinerja & evaluasi berkala
